# Manual Trade Journal

The manual trade journal records trades the user chose to enter manually.

## Current Status
Implemented for Version 1.0.

## Related Commands
- `python main.py trade-add`
- `python main.py trade-add-latest-alert --ticker TICKER --shares SHARES`
- `python main.py trade-list`
- `python main.py trade-close --trade-id ID --exit-price PRICE`

## Role
The journal is the evidence layer for [[Trade Monitor]], [[Trade Analytics]], and future [[Long-Term AI Direction|AI learning]].
