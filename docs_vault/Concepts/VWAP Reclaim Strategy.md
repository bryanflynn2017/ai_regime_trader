# VWAP Reclaim Strategy

VWAP Reclaim looks for price moving from below VWAP to above VWAP with enough relative volume.

## Current Status
Implemented as one Version 1.0 setup type.

## Role
One of the core strategies evaluated by [[Setup Scanner]] and later by [[Trade Analytics]].
