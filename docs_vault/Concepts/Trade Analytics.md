# Trade Analytics

Trade analytics summarizes closed manual trades to reveal what is working.

## Current Status
Implemented for Version 1.0.

## Related Commands
- `python main.py trade-analytics`
- `python main.py trade-analytics --include-shadow`
- `python main.py trade-analytics --include-shadow --clean-shadow-only`

## Role
Analytics reports win rate, P&L, profit factor, expectancy, and breakdowns by ticker, setup type, rank, score, and confidence.

For [[Shadow Forward Testing]], analytics also supports clean-sample reporting,
large loser diagnostics, hypothetical filters, and [[Candidate Rule Tracking]].
