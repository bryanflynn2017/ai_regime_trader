# Dashboard

The dashboard is a read-only Streamlit view of state, logs, setup scans, trades, monitor results, and analytics.

## Current Status
Implemented for Version 1.0; charts can improve.

## Related Commands
- `python main.py dashboard`
- `streamlit run dashboard/app.py`

## Role
The dashboard supports review, not execution.
