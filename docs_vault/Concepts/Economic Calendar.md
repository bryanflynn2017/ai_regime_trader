# Economic Calendar

Economic calendar support tracks high-impact events and attaches context to alerts and trades.

## Current Status
Planned Priority 1 integration.

## Events To Track
- CPI
- FOMC
- jobs reports
- GDP
- major earnings/news days

## Role
Tag [[Setup Alerts]] and [[Manual Trade Journal|manual trades]] with event context so [[Trade Analytics]] can answer questions like "should I avoid trading during high-impact events?"
