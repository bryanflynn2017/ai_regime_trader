# Trade Action Cards

Trade action cards summarize a setup into an actionable manual trade plan.

## Current Status
Implemented for Version 1.0.

## Role
Cards support human decision-making by showing entry, stop, targets, risk/reward, reason, warnings, and optional suggested sizing.

## Related Commands
- `python main.py setup-scan --watchlist mega_caps --timeframe 5Min --account-equity 100000`
- `python main.py setup-scan-loop --watchlist mega_caps --timeframe 5Min`
