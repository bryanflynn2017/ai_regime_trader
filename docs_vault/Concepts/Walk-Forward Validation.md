# Walk-Forward Validation

Walk-forward validation evaluates strategy behavior across rolling train/test windows.

## Current Status
Implemented as a validation tool.

## Related Commands
- `python main.py walk-forward --synthetic`
- `python main.py walk-forward --csv path/to/data.csv`

## Role
It helps test whether ideas survive changing market periods and reduces overfitting risk.
